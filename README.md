# Praktikum Pemrograman Berbasis Web - Kelas A

Repositori ini berisi kumpulan kode program, tugas, dan proyek praktikum untuk mata kuliah **Pemrograman Berbasis Web (Kelas A)**.

## 📌 Isi Repositori
- **Tugas Mingguan:** Latihan dan penyelesaian modul praktikum.
- **Proyek Web:** Implementasi pengembangan aplikasi web (*frontend* & *backend*).
- **Materi/Latihan:** Akses cepat untuk kode sampel selama sesi laboratorium.

## 🛠️ Teknologi yang Digunakan
- **Frontend:** HTML5, CSS, JavaScript
- **Backend:** PHP 
- **Database:** MySQL / MariaDB
- **Tools:** VS Code, Git, XAMPP

## Cara Menjalankan Program
php -S localhost:8000
